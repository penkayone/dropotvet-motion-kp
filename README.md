# KOMETA × DropOtvet: motion-ролик

Коммерческое предложение KOMETA для DropOtvet на motion-ролик о смене фирменного стиля.
Стиль повторяет КП DropOtvet по ребрендингу.

Статический сайт: HTML, CSS и JavaScript, без сборки. Страница закрыта от индексации.

- `index.html` разметка и тексты
- `style.css` базовая система KOMETA
- `wow.css` анимации, блоки КП и телефоны с роликами (в конце файла)
- `script.js` частицы и появление блоков при прокрутке
- `wow.js` прогресс, навигация, счетчики, ролики
- `video/` три примера роликов и их постеры, порядок задан Яном
